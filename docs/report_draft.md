## p2. 아이디어명 / 기술요약

**2. 아이디어명**: RoadPush (2026 AI 라이프 아이디어 챌린지 수상 후보작) — 번호 표기는 KEIT 확인 후 기재

**3. 기술요약 (3줄)**
1. 보행자 시점 촬영 영상을 경량 세그멘테이션 모델(RF-DETR-Seg, Apache 2.0)로 분석해 보도면과 주정차 차량·이륜차·입간판·볼라드 등 장애물을 픽셀 단위로 분할한다.
2. 분할 결과 위에서 스캔라인별 **유효보행폭 비율**(실제로 지나갈 수 있는 최대 폭 ÷ 원래 보도 폭)을 계산하고, 보도 소멸·폭 협소·공사·단차 4가지 단절 유형을 판정한다.
3. 프레임을 GPS로 서울 보행 링크에 매핑해 링크별 위험도(0~100)를 산출하고, 지자체 담당자가 지도에서 조치 우선순위와 조치 전·후 변화를 확인하는 웹 대시보드로 제공한다.

(그림: 파이프라인 도식 — 영상 → 분할 → 비율 → 링크 점수 → 지도)

차별점
- '단절'은 객체가 아니라 **공간 관계**다. 객체 검출에 그치지 않고, 분할 마스크 위 기하 후처리로 지나갈 수 있는 폭을 정량화했다.
- 차도 위 차량은 제외하고 **보도 위 장애물만** 센다(발점 판정). 맨홀·배수구 덮개는 통행 가능면, 가로수 보호틀은 통행 불가로 구분.
- 대형 파운데이션 모델(SAM 3)은 라벨링 teacher로만 쓰고, 배포는 CPU에서도 도는 경량 모델로 — 라이선스·운영비 모두 지자체 도입에 맞춤.
- 휠체어 프로필(임계 0.5→0.7, 단차 가중↑)로 보행약자 관점 확장.

## p4. 애로점 / 기대효과

**6. 개발 과정에서 애로점과 해결**
- AI Hub 보도면 데이터에는 장애물 라벨이, 장애물 데이터에는 일부 보도면 라벨이 없다 → 두 데이터를 합치면 '안 그린 차량'을 배경으로 학습하는 문제. SAM 3 의사 라벨로 결측을 채우고 {결과}.
- 원근 때문에 픽셀 폭을 m로 바꾸기 어렵다 → 제안자 답변대로 **비율**을 기본 지표로, 법정 유효폭 1.2 m는 보조 지표로.
- GPS 오차(도심 10 m 내외) → 이동평균 + 링크 스냅 거리 임계 15 m, 애매한 프레임 폐기.
- 서울시 도보네트워크 API 대신 OSM 보행 네트워크로 링크를 구성(동일 스키마, 교체 가능).

**7. 기대효과**
- 지자체: 민원·순찰 의존 점검을 '촬영 → 자동 리포트'로 전환. 링크별 우선순위로 단속·정비 예산 배분 근거 확보.
- 보행약자: 휠체어·유모차가 지나갈 수 없는 구간을 정량적으로 드러내 디지털 포용 정책의 기초 데이터 제공.
- 확장: 공공 차량·배달 이륜차 블랙박스, 청소차 카메라에 그대로 적용 가능(모델 경량, CPU 추론). 시간대별 재분석으로 불법주정차 상습 구간 탐지.
